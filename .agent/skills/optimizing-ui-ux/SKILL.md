# Optimizing UI/UX

## When to use this skill
- When designing or building user interfaces.
- When handling images or media.
- When implementing file interactions.
- When reviewing accessibility or usability.

## Workflow
1.  **Performance Check**: Ensure image handling is optimized.
2.  **Interaction Check**: Verify drag-and-drop functionality is present where applicable.
3.  **Usability Check**: Ensure the UI is intuitive for non-technical users.

## Instructions
- **Image Performance**:
    - Optimize images for fast loading.
    - Use appropriate formats (WebP, etc.) and lazy loading.
- **Drag and Drop**:
    - Always include drag-and-drop functionality for file uploads or reordering.
- **Intuitive Design**:
    - Design for non-technical users.
    - Use clear labels, feedback, and simple flows.
    - Avoid technical jargon in the UI.
