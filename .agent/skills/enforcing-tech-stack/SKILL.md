# Enforcing Tech Stack

## When to use this skill
- When starting a new project.
- When choosing technologies for a feature.
- When refactoring or reviewing code cleanliness.

## Workflow
1.  **Check Tech Stack**: Ensure React is used for frontend and Node.js for backend.
2.  **Verify Code Quality**: Prioritize clean, readable code over clever shortcuts.

## Instructions
- **Frontend**: ALWAYS use React.
- **Backend**: ALWAYS use Node.js.
- **Code Style**:
    - Prioritize readability and maintainability.
    - Avoid complex one-liners or obscure hacks.
    - Write explicit code that explains itself.
